# Title

Lighten background and center heading in project/hello_world.html

---

# Purpose

The owner reviewed the page delivered under IMPLEMENTATION_CONTRACT_0003 and asked for two visual refinements: a softer background color and a centered heading, so the page reads better on screen. Making this its own contract keeps the visual-refinement decision separate from and traceable against the original implementation, rather than silently rewriting an already-approved deliverable.

---

# Intent

This contract deliberately touches only the existing project/hello_world.html's CSS: it changes the body's background color to a lighter blue and centers the "HELLO WORLD!" heading both horizontally and vertically within the page. It deliberately does not change the page's text content, document structure, add JavaScript, or touch any other file. It builds directly on project/hello_world.html as delivered under IMPLEMENTATION_CONTRACT_0003, and does not reopen or alter project/checklist.md (IMPLEMENTATION_CONTRACT_0002), which already reached APPROVED status and stands as the historical record of the original plan.

---

# Current State

Per memory/CURRENT_STATE.md (regenerated by the Discovery Engine before this contract) and by reading project/hello_world.html directly: the file exists with a <style> block setting `body { background-color: blue; }` and `h1 { color: black; }`, and a <body> containing a single unstyled `<h1>HELLO WORLD!</h1>` with no centering or layout rules applied (it renders at the default top-left position). project/checklist.md, project/README.md, and project/hello.md are unchanged since IMPLEMENTATION_CONTRACT_0003 and are not affected by this change.

---

# Inputs

The existing project/hello_world.html as delivered under IMPLEMENTATION_CONTRACT_0003. No other module, API, or data is used.

---

# Outputs

The modified project/hello_world.html: the body's background color changed from blue to lightblue (#ADD8E6), and the <h1>HELLO WORLD!</h1> heading centered both horizontally and vertically within the viewport. No other file is created or modified.
