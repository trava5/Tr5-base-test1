This contract deliberately implements exactly the page project/checklist.md already describes: a minimal static HTML document with a blue page background and black "HELLO WORLD!" text. It deliberately does not add JavaScript, external stylesheets/scripts, a build step, or any framework, and it deliberately does not modify project/checklist.md, project/README.md, or project/hello.md — it only adds one new, self-contained file alongside them. It relates to the existing architecture only through project/, the location documented by project/README.md as where every contract's actual output lands, and through project/checklist.md, whose own 'Future Evolution' note explicitly deferred this exact implementation to a later contract.

# Functional Requirements

## Point 1

SHALL: Create the file project/hello_world.html containing a minimal, valid HTML document (starting with <!DOCTYPE html>, followed by <html>, <head>, and <body> elements) that implements every step of project/checklist.md: the <body> element's background is set to blue via CSS (background-color: blue, either inline via a style attribute or in a <style> block inside <head>), and the <body> contains a visible element (e.g. a heading or paragraph) whose text content is exactly "HELLO WORLD!" and whose CSS color is set to black (color: black or color: #000000, inline or via the same <style> block).

Acceptance criteria:
- File project/hello_world.html exists after implementation, using exactly this lowercase_with_underscores filename.
- No file named project/HELLO_WORLD.html or any other case variant exists in the repository.
- The file begins with <!DOCTYPE html> and contains a complete <html>, <head>, and <body> structure.
- The file contains a CSS declaration setting the body's background to blue (e.g. background-color: blue), applied via an inline style attribute on <body> or a <style> block in <head>.
- The file contains an element whose text content is exactly "HELLO WORLD!" (matching case and punctuation exactly).
- That same element (or an ancestor covering it) has a CSS color declaration set to black (color: black or color: #000000).
- The file contains no <script> tag and no reference to any external .css or .js file (no <link rel="stylesheet"> or <script src=...>).
- project/checklist.md, project/README.md, and project/hello.md are byte-for-byte unchanged.
- No file other than project/hello_world.html is created, modified, or deleted.
