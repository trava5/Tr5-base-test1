The implementation deliberately does only one thing: create a single small Markdown file with a short welcome note, named in lowercase_with_underscores per AGENTS.md's naming convention for free-form prose files (README.md is the only carved-out exception to the UPPERCASE_WITH_UNDERSCORES.md rule, which applies only to documents that carry a rule, role, state, or contract).
