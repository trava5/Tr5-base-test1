# HTML Page Checklist: Blue Background with "HELLO WORLD!"

- Create a new HTML file for the page.
- Add the basic HTML document structure (doctype, html, head, and body elements).
- Set the body's background color to blue.
- Add an element inside the body containing the text "HELLO WORLD!".
- Set that "HELLO WORLD!" text's color to black.
- Save the file and open it in a browser to check that the background is blue and the "HELLO WORLD!" text is black.
